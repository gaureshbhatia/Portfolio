BeforeULeave

Your Home's energy,
at a glance.

01

The question

How can we make it easier for people to check selected household appliances before leaving home? People often forget whether they switched off a light, fan, heater, or iron. This project explores whether a small display near the front door can show appliance status clearly by room, so users can make a quick final check before leaving.

02

The approach

We are building a customizable ESP32 door display using a 2.8-inch ILI9341 TFT screen. The interface shows each room as a movable block, with the appliances in that room listed inside it. Appliance data is first generated by a realistic simulator and sent over Wi‑Fi using MQTT; certified smart plugs can replace the simulator later. Users can rearrange room blocks to personalize the layout, and the ESP32 saves their preferred arrangement.

03

Expected outcome

The expected outcome is a working door-side dashboard that gives users a quick, room-by-room view of their appliances before leaving home. The display will update appliance status in real time, allow users to personalize the room-block layout, and remain easy to read from a distance. The project will also measure update speed, test Wi‑Fi/server failure behavior, and evaluate whether showing power usage is more helpful than showing status alone.

LinXray

We will think,
so you can click.

VIEW CODE ↗
01

The question

How can people make a more informed decision before opening an unfamiliar link? A URL can be difficult to judge from its appearance alone, and checking it should not require sharing or analyzing a person's browsing history. LinXray explores whether an on-demand link analysis can explain potential warning signs clearly, helping users understand what might make a link suspicious before they choose to open it.

02

The approach

LinXray is a web app that lets a user submit a link for analysis when they want to check it. The analysis runs using Docker and Reka AI, rather than relying on a record of the user's browsing history. After the result appears, a chat window lets the user ask follow-up questions and request clarification, making it easier to understand the analysis before deciding what to do next.

03

Expected outcome

The expected outcome is a straightforward way to review a link and better understand its potential risks before opening it. LinXray will provide an analysis on demand and a chat interface for follow-up questions, so users can get clarification about the result. The project aims to make link checks more understandable and useful without basing them on browsing history.
